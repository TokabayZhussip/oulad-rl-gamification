# oulad-rl-gamification

**Адаптивная геймификация на основе обучения с подкреплением (RL): надёжность и защита от отравления данных**

*Adaptive gamification based on reinforcement learning: reliability and protection against data poisoning*

Репозиторий содержит код и результаты экспериментов к статье:

> Жүсіп Т.Н., Ламашева Ж.Б., Ахаева Ж.Б. Адаптивная геймификация на основе RL: надёжность и защита от отравления данных. Евразийский национальный университет им. Л.Н. Гумилёва, Астана, Казахстан. *(статья направлена в печать)*

## О проекте

RL-агент еженедельно выбирает элемент геймификации (бейдж, рейтинг, челлендж или отсутствие воздействия) для каждого обучающегося, чтобы повысить его вовлечённость. Модель поведения обучающихся построена по реальным данным **OULAD** (Open University Learning Analytics Dataset).

Проводятся пять экспериментов:

| Эксперимент | Что проверяется |
|---|---|
| **E1** | Сравнение 8 стратегий: статичные, Q-learning, SARSA, контекстный бандит, теоретический оптимум (DP) |
| **E2** | Чувствительность к гипотезе об эффектах игровых элементов |
| **E3** | Надёжность: шум во входных данных и отказы RL-модуля с резервным правилом |
| **E4** | Безопасность: атаки отравления данных (боты и «умные» фармеры) и 5 методов защиты |
| **E5** | Проверка на каждом из 7 курсов OULAD |

## Основные результаты

- Q-learning повышает вовлечённость на **34,3%** по сравнению с отсутствием геймификации и на **4,1%** по сравнению с экспертной эвристикой (p = 0,002), достигая **98,7%** теоретического оптимума.
- Резервное правило при отказе RL-модуля сохраняет **94,5%** качества (без него — 74,4%).
- Атака ботами (20%) завышает прогноз вовлечённости на **24,6%**; робастная z-оценка (MAD) снижает искажение модели в **14 раз**.
- Против маскирующихся атак частично эффективен только критерий согласованности активности и успеваемости.

Полные результаты: [`results_v2/summary.txt`](results_v2/summary.txt).

## Данные

Датасет OULAD **не входит** в репозиторий из-за размера (около 450 МБ). Его нужно скачать отдельно:

- официальная страница: https://research.stem.open.ac.uk/ouanalyse/dataset/
- лицензия: CC BY 4.0

Распакуйте CSV-файлы в папку `data/`, чтобы получилось `data/studentVle.csv`, `data/studentAssessment.csv`, `data/assessments.csv` и т. д.

## Установка и запуск

Требуется Python 3.11 или новее.

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
```

Запуск:

```bash
python oulad_experiments.py          # полный эксперимент на данных OULAD (около 3–5 минут)
python oulad_experiments.py --demo   # проверка на синтетических данных, без OULAD
python oulad_experiments.py --fast   # ускоренный режим с меньшим числом повторов
```

Результаты сохраняются в папку `results_v2/`.

## Ограничения

В OULAD нет данных о геймификационных воздействиях, поэтому эффекты бейджей, рейтингов и челленджей заданы гипотезой (массив `BASE_EFFECT` в коде). Их влияние на выводы оценивается в эксперименте E2.

## Дополнительные проверки

| Скрипт | Что проверяет | Результаты |
|---|---|---|
| `revision_checks.py` | R1: бандит vs Q-learning (парный тест, объём обучения); R2: перенос стратегии (студенты 50/50, 2013 → 2014); R3/R4: априорные пороги MAD и согласованности, каскад | `results_revision/summary_revision.txt`, `R1_bandit_vs_q.csv`, `R2_split.csv`, `R3_R4_thresholds.csv` |
| `r3c_reference.py` | Пороги и опорная статистика (медиана/MAD, регрессия) по чистым данным 2013 г., атака и оценка на 2014 г. — **вариант, приведённый в статье** | `summary_R3c.txt`, `R3c_reference.csv` |
| `r3b_calibrated.py` | Промежуточный вариант: пороги по 2013 г., но центр и масштаб MAD по самой очищаемой выборке (в статье не используется) | `summary_R3b.txt`, `R3b_calibrated.csv` |
| `r5_ablation.py` | R5: абляционный анализ критерия согласованности (без веса активности, двусторонний остаток, без успеваемости, MAD); Precision, Recall, F1, искажение | `summary_R5.txt`, `R5_ablation.csv` |

Запуск из корня репозитория (данные OULAD в папке `data/`):

```bash
python revision_checks.py
python r3b_calibrated.py
python r3c_reference.py
```
